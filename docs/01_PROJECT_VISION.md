# CyberSecOS

CyberSecOS is a personal cybersecurity learning platform.

Its purpose is to take a complete beginner and transform them into a job-ready SOC Analyst.

The platform should focus on:

- Networking
- Windows Security
- Linux Security
- SIEM
- Threat Hunting
- Incident Response
- Detection Engineering
- Cloud Security

The application will be used by one user only.

Success means:

- Capable of passing Security+
- Capable of passing SC-200
- Capable of passing CySA+
- Capable of performing SOC Analyst tasks
- Capable of succeeding in interviews

Target:
20% theory
80% hands-on labs
